# myim

複数のローカル辞書と拡張辞書を使うmacOS向けInput Method

GyaimとSKKにインスピレーションを受けて制作しました

## 設計思想

myimは、日本語入力と英語入力を別のモードへ分けず、ローマ字から必要な表記を選ぶInput Methodです

- 変換前はローマ字を保ち、候補を選んだ時だけ日本語や別の表記へ変換
- 辞書の基本単位を「読みと出力」の単純な組にし、言語固有の複雑さをコアへ持ち込みすぎない
- 基本辞書、ユーザー辞書、共有可能な拡張辞書を重ね、個人の語彙と共同体の語彙を両立
- 辞書登録を別アプリの作業にせず、普段の入力から連続して実行
- 選択履歴、次入力学習、動詞活用、誤入力補完、外部情報を交換可能な補助層として追加
- ローカル変換を基本とし、通信を伴う機能は任意で有効化
- 候補に対応するCosenseページや辞書をそのまま表示し、語の意味や背景へ入力中に接続

複雑な自然言語処理を前提にするのではなく、単純な辞書検索を中心に、必要な能力を独立して重ねられる構成を目指します

## 必要環境

- macOS 13以降
- Swift 6以降
- Apple Translationを使う機能はmacOS 15以降

## 基本操作

入力中はローマ字をそのまま表示し、候補を選択した時点で日本語へ変換します

| 操作 | 結果 |
| --- | --- |
| 文字入力 | 候補をインクリメンタルに更新 |
| Tab | 先頭候補を選択し、続けて押すと次候補へ移動 |
| Shift＋Tab | 前候補または「もしかして？」候補へ移動 |
| 左右矢印 | 候補未選択なら入力カーソルを移動、候補選択後は候補を移動 |
| 上下矢印 | 候補選択後に候補を移動 |
| Return | 選択候補を確定、未選択ならローマ字のまま確定 |
| Space | 入力または選択候補を確定して半角空白を入力 |
| Escape | 候補選択を解除してローマ字表示へ戻る |
| Delete | 入力を削除して候補を更新 |
| Option＋Delete | 直前の単語単位を削除して候補を更新 |
| Command＋Delete | 未確定文字列全体を削除して候補を閉じる |
| Command＋O | 外部情報パネルのページを既定ブラウザで開く |
| F6 | 入力をひらがな候補へ直接変換 |
| F7 | 入力を全角カタカナ候補へ直接変換 |
| F8 | 入力を半角カタカナ候補へ直接変換 |
| F9 | 入力を全角英数字候補へ直接変換 |
| F10 | 入力を半角英数字候補へ直接変換 |

F6〜F10は入力位置の未確定範囲だけを変換し、候補パネルや外部情報パネルへフォーカスを移しません

入力可能な場所で確定済みの文字列を選択してTabを押すと、辞書から読みを逆引きして再変換を開始します
Escapeまたはフォーカス移動では元の文字列へ戻します
閲覧専用の文字列など、Tabがmyimへ届かない場所では利用できません

候補パネルは入力位置から少し間隔を空け、画面内に最大7件を表示します

パネル下部には現在の状態で使える主要なショートカットを表示します

Tabを続けて押すと8件目以降も選択できます

辞書に候補がない場合も、ひらがなと片仮名を表示します

記号入力、表記揺れ、連濁、候補順、動詞活用の詳細は`MISCELLANEOUS.md`を参照してください

## 主な機能

### ローカル変換

- Mozc OSS辞書を主辞書として一般的なかな漢字変換を提供
- TKG Japanese-English Learner’s Dictionaryで日本語語彙を補完
- myim補完辞書で上流辞書に不足する語句を追加
- 終止形から動詞のて形、た形、否定形、丁寧形、可能形、受身形、使役形などを生成
- macOSの英語補完から英単語候補を表示
- 1文字分の入力ではひらがな・片仮名を最優先
- 2文字分以上では完全一致する直接候補、直近に選択した候補、かな候補、その他の順で表示

同梱辞書はMozcとTKGJEの原本ではなく、myimに必要な読みと候補を抽出した派生データです

辞書の構成と変換方法は`docs/DICTIONARY_DATASETS.md`、出典と配布条件は`docs/DICTIONARY_LICENSES.md`を参照してください

### 便利機能

- 計算: `2+1=`から`3`を候補として表示
- 文字種変換: F6〜F10でひらがな、カタカナ、英数字へ直接変換
- 日付: `kyou` `kinou` `ashita`から対象日を候補として表示
- 時刻: `ima` `jikoku`から現在時刻を候補として表示

計算は四則演算、小数、括弧に対応し、式の末尾が`=`の場合だけ実行します

日付と時刻は設定の「日時の動的候補を表示」を有効にすると利用できます
書式は`YYYYMMDD` `YYYY-MM-DD` `HH:mm:ss`などをカンマ区切りで指定できます

### 「もしかして？」候補

誤入力の補助候補を、通常候補とは別の「もしかして？」パネルへ表示します

- 削除索引とローマ字向け重み付き編集距離で誤入力を補完
- 隣接キー、母音の脱落、文字の入れ替え、長音、`n`表記を優先
- 誤入力コストと基本辞書順を組み合わせて候補を順位付け
- 過去に選択した補助候補を直近の選択順で優先
- Shift＋Tabで選択を開始
- Tabと矢印キーで移動
- Returnで確定
- Escapeで通常候補へ戻る
- 通常候補の選択をEscapeで解除すると「もしかして？」候補も再表示

### ユーザー辞書

入力中のローマ字を読みとして、任意の文字列を登録できます

1. myimで読みを入力
2. Option＋Returnで辞書登録モードへ移る
3. 登録したい文字列を入力するかCommand＋Vで貼り付ける
4. Returnで入力を追加し、最後にもう一度Returnで登録を確定

通常入力中のCommand＋Vは辞書登録を開始せず、入力先アプリへ通常の貼り付けとして渡します

辞書登録中は各パネルにアクセント色の枠と「登録したい文字列を入力」の見出しを表示します

登録した候補を選択してCommand＋Xを押すと、入力中の読みが完全一致していなくてもユーザー辞書から削除します
同じ候補が基本辞書などにも存在する場合、基本辞書側の候補は削除しません
削除した文字列は誤削除に備えてクリップボードへコピーします

保存先

```text
~/Library/Application Support/myim/user/dictionary.txt
```

### 次の入力候補

確定した語句のつながりをローカルで学習し、次に入力される可能性が高い語句を表示します

同じ語句の後で直前に選んだ候補を先頭にし、2番目以降は累計頻度と最終使用順で表示します

- Tabで選択を開始
- Tab、Shift＋Tab、矢印キーで移動
- Returnで確定
- 文字入力を始めると選択中の候補を確定して新しい入力へ移行
- 未選択のまま5秒経過すると自動で終了
- 最大256文脈、1文脈につき最大8候補だけを保持

入力ソースメニューの「次入力履歴を削除」から学習内容を削除できます

### 辞書と外部情報の表示

候補選択中に次の補助パネルを表示できます

- macOS標準辞書の語義を候補パネルの上または下へ表示
- CosenseやWikipediaなどのWebページを候補パネルの左または右へ表示
- 「もしかして？」パネルを入力行と候補パネルに重ならない位置へ表示
- Webパネル内のクリックとスクロールに対応
- タイトルバーの「ブラウザで開く  ⌘O」またはCommand＋Oで現在のページを既定ブラウザへ表示
- パネル操作後も未確定文字列と候補選択を維持
- Escapeまたは次のキー入力で候補選択へ戻る

候補選択前は入力中のローマ字をmacOS標準辞書で検索し、入力に合わせて語義を更新します

候補選択へ移ると、選択中の候補を検索対象に切り替えます

外部情報パネルは`%s`を検索語として含む任意のHTTPまたはHTTPS URLを指定できます

表示までの待機時間も設定できます

macOS標準辞書の利用範囲は`docs/MACOS_DICTIONARY.md`を参照してください

### 外部候補とWeb検索

必要な機能だけを設定から有効にできます

- Wikipediaの記事名候補
- Apple Translationによる日本語から英語への候補
- Command＋Returnで選択候補を確定してWeb検索

Web検索URLは`https://www.google.com/search?q=%s`のように指定します

Wikipedia、Apple Translation、Web検索は初期状態で無効です

### Cosense拡張辞書

指定したCosenseプロジェクトの`dictionary`ページを共有語彙や固有名詞の拡張辞書として使用します

```text
https://scrapbox.io/project-name
```

ページの記述形式

```text
miru
 見る
 診る

ikiru
 生きる
 活きる
```

- 入力ソースメニューの「Cosenseプロジェクトを設定…」からURLを指定
- 設定直後に同期し、プロジェクト別にローカルへキャッシュ
- 「Cosense辞書を更新」またはCommand＋Option＋Control＋Rで再同期
- 公開プロジェクトとログイン済みのプライベートプロジェクトに対応
- 外部情報パネルは汎用ブラウザ補助プロセスで表示
- クリック、スクロール、ログイン欄への文字入力が可能
- CookieなどのWebサイトデータは補助プロセスの永続WebKitデータストアだけで管理
- Cosenseへのユーザー辞書の書き戻しは行わない

## 設定

入力ソースメニューの「myim設定…」から開きます

コア機能はローマ字入力とローカル候補生成です

それ以外は個別にオン・オフできます

- 常時使用するローカル基本辞書とユーザー辞書
- オン・オフできるCosense拡張辞書
- 英語補完と外部候補
- 誤入力補完
- 次入力候補
- macOS辞書パネルと外部情報パネル
- Web検索と検索先URL

設定変更は現在の入力から反映し、myimの再起動後も維持します

## ビルドとインストール

```shell
./Scripts/install-macos-im.sh
```

初回だけ「システム設定」→「キーボード」→「テキスト入力」→「編集」から`myim`を追加します

更新時も同じコマンドで最新コードをビルドして置き換えます

インストール先

```text
~/Library/Input Methods/myim.app
```

ログアウトや再起動は不要です

## 実装予定

### 機能追加

- 辞書登録と外部情報パネルのInputMethodKit実機テストを拡充
- カーソル位置の入力モードインジケータをライト・ダーク両モードで安定化
- 変換エンジンをmacOS固有実装から分離してWindowsへ対応

### リファクタリング

- 基本辞書、ユーザー辞書、Cosense辞書の読み込み、更新、キャッシュ、変換エンジン再構築を共通管理
- ユーザー辞書の登録、削除、保存、候補更新を入力制御から分離
- Wikipedia、翻訳、英語補完、Web検索の外部候補処理を共通管理
- 各パネルの配置、表示、フォーカス復帰を共通管理
- UserDefaultsの設定キー、初期値、読み書きを型付き設定へ集約
- `InputController`に残る候補選択と確定を`MyIMECore`へ移動
- Cosense、外部候補、誤入力補完、次入力予測、日時候補、外部情報表示を拡張機能として分離
- 通常候補だけでなく拡張機能の候補も`CandidatePipeline`で順位付け
- 拡張APIと標準拡張を独立したSwift Package Targetへ分離
- 必要性と安全性を確認した機能だけ、将来XPCなどの外部プラグイン方式を検討
