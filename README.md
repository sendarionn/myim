# myim

複数のローカル辞書とCosense拡張辞書を使うmacOS向けInput Method

実装の更新履歴は`HISTORY.md`を参照してください

入力変換の細かな調整内容は`MISCELLANEOUS.md`を参照してください

## 必要環境

- macOS 13以降
- Swift 6以降

## 入力と変換

- 英字キーで入力したローマ字を未確定文字列としてそのまま表示
- 入力中のASCII記号を保持し、記号前のローマ字候補を継続して変換
- 入力に応じて日本語候補と英語補完候補を表示
- ASCII記号から句読点、括弧、長音などの日本語記号候補を表示
- 入力または削除のたびにローマ字の前方一致候補を更新
- 全候補を内部で検索し、選択中の位置を含む最大7件を候補ウィンドウへ表示
- Spaceを続けて押すと8件目以降の候補へ移動
- 矢印キーで候補セルの上下左右へ移動
- 候補は文字列の長さに合わせた可変幅セルで縦横に表示
- 候補パネルは入力位置の近くでディスプレイ内に収まるよう配置
- Spaceで先頭候補を選択
- 続けてSpaceを押すと次候補へ移動
- 候補を選択した時点で未確定文字列を候補のひらがなや漢字へ切り替え
- 候補選択中に次の文字を入力すると選択候補を確定して新しい入力を開始
- `〜個`などの候補はプレースホルダーの`〜`を除いて確定
- OS辞書パネルは候補パネルの上、収まらない場合は下へ表示
- Cosenseパネルは候補パネルの右、収まらない場合は左へ表示
- OS辞書とCosenseを独立したパネルとして表示
- Cosenseパネル内をクリック、スクロール、キーボードで操作
- Cosenseパネル内のログインCookieを保存し、次回表示でも再利用
- CosenseパネルとOS辞書パネルが重ならないよう配置と高さを調整
- Cosenseに実在しない候補ページではCosenseパネルを非表示
- HTTP `200`でも未作成状態のページは実在ページとして扱わない
- 候補未選択の入力中は入力中のローマ字に対応するCosenseページを表示
- 候補選択を開始すると選択候補に対応するCosenseページへ切り替え
- 候補選択を解除すると入力中のローマ字に対応するページへ戻る
- 候補選択中のReturnで選択候補を確定
- 候補未選択のReturnで入力したローマ字を確定
- Deleteで入力中の文字を削除して候補を再検索
- Escapeで候補選択を解除してローマ字表示へ戻る

入力中のローマ字は候補を選択するまで変換しません

辞書にない入力でも、ひらがなと片仮名を候補へ表示します

入力表記の正規化、記号、候補順、連濁、動詞活用の詳細は`MISCELLANEOUS.md`を参照してください

## 辞書構成

myimは役割の異なる辞書を1つへ結合せず、独立したレイヤーとして検索します

| 辞書 | 元データ | myimで保持する内容 | 用途 |
| --- | --- | --- | --- |
| Mozc基本辞書 | `google/mozc`のOSS辞書 | かな読みと変換候補 | 一般的なかな漢字変換の主辞書 |
| TKGJE基本辞書 | TKG Japanese-English Learner’s Dictionary | ローマ字読みと日本語見出し語 | 学習者向け日本語語彙の補助 |
| myim補完辞書 | myim独自データ | ローマ字読みと変換候補 | 上流辞書で不足した語句の回帰補完 |
| ローカルユーザー辞書 | ユーザー登録 | ローマ字読みと変換候補 | 個人用語彙と優先候補 |
| Cosense拡張辞書 | 指定プロジェクトの`dictionary`ページ | ローマ字読みと変換候補 | 共有語彙、固有名詞、プロジェクト固有語彙 |

### Mozc基本辞書

かな漢字変換の主辞書としてMozc OSS辞書を使用します

同梱ファイルはオリジナルのMozc辞書ではありません

Mozc OSSの原データから、myimの基本辞書形式へ必要なかな読みと候補だけを抽出した派生データです

変換元の`dictionary_oss`にはIPAdic、沖縄辞書、Mozcで追加された語彙が含まれます

- 約28万読み、約38万候補、約9.9MB
- Mozc候補コスト7000以下を収録
- 1読みにつき候補コスト順で最大32候補
- 同一のかな表記と重複候補を除外
- 前方一致検索は1回の入力更新につき最大2048候補
- 文脈ID、品詞、活用型、元の候補コストは実行時辞書に保持しない

`kakujuu`から`拡充`、`kangaeru`から`考える`など、通常の日本語変換を主に担当します

`Scripts/convert-mozc-dictionary.py`で原データを変換します

### TKGJE基本辞書

CC0のTKG Japanese-English Learner’s Dictionaryを補助辞書として使用します

同梱ファイルはオリジナルのTKGJEではありません

公開索引から、myimの基本辞書形式へローマ字読みと日本語見出し語だけを抽出した派生データです

- 27,602読み、29,968候補、約607KB
- Basic、Core、Generalの語彙階層を収録
- 語義、用例、語彙階層は実行時辞書に保持しない
- `速い／早い`のような別表記は`速い`と`早い`へ分割

Mozcとは読みの形式と語彙の性格が異なり、ローマ字で整理された学習者向け日本語語彙を補います

英語の語義や用例は抽出していないため、TKGJEは現在のmyimで英訳候補の生成には使用しません

`Scripts/convert-tkgje-dictionary.py`で公開索引を変換します

IMの起動時にTKGJEの公開索引を確認し、更新がある場合は次の場所へ保存して実行中の候補へ反映します

```text
~/Library/Application Support/myim/basic/dictionary.txt
```

入力ソースメニューの「TKGJE基本辞書を更新」から手動確認もできます

更新に失敗した場合は、最後に保存した辞書または同梱辞書を継続して使用します

Mozc基本辞書はビルド時に生成した版を使用し、実行中の自動更新対象には含みません

### myim補完辞書と動詞活用

myim補完辞書はMozcとTKGJEで不足した読みと表記だけを補います

- 上流辞書を更新しても補完候補を維持
- `kakujuu`から`拡充`のような欠落例を回帰テストで確認
- 上流辞書に同じ候補がある場合は重複を除去

動詞活用候補はMozcまたはTKGJEに収録された終止形から生成します

- 五段動詞のて形、た形、否定形、丁寧形
- 一段動詞のて形、た形、否定形、過去否定形、丁寧形、希望形
- `する`と`来る`の不規則活用
- `kangaete`から`考えて`
- `kakanai`から`書かない`
- `benkyoushite`から`勉強して`

基本辞書は品詞と活用型を保持しないため、一段動詞と五段動詞を完全には判別できません

### 候補の優先順位

ひらがな一文字になる入力では、ひらがな、片仮名、ローカルユーザー辞書、その他の順です

それ以外は次の順を基本とします

1. ローカルユーザー辞書
2. Cosense拡張辞書
3. Mozc完全一致
4. TKGJE完全一致
5. 動詞活用
6. myim補完辞書
7. ひらがなと片仮名
8. 英語補完と公式外部候補
9. Mozc前方一致
10. TKGJE前方一致

同じ候補は先に現れたものだけを残します

同じ候補レイヤー内では直近に選択した候補を優先します

辞書の比較と変換方法は`docs/DICTIONARY_DATASETS.md`、出典と配布条件は`docs/DICTIONARY_LICENSES.md`を参照してください

## ユーザー辞書

ローカルユーザー辞書へ登録します

1. 登録する候補文字列をクリップボードへコピー
2. IMで読みを入力
3. 入力中に`Command＋V`を押す
4. 確認なしで登録し、macOS標準の貼り付けでクリップボードの文字列を1回だけ確定
5. 登録候補が以降の変換候補へ即時追加

物理キーコードとキー配列適用後の文字情報の両方で`Command＋V`を認識します

選択文字列を登録する場合

1. 入力先アプリで候補文字列を選択
2. 入力ソースメニューから「選択文字列を辞書登録…」を選択
3. ローマ字の読みを入力
4. 「登録」を押すとユーザー辞書へ保存

選択文字列を取得できないアプリでは、クリップボードの文字列を登録候補として使用します

複数行の選択文字列は改行と連続空白を単一Spaceへ変換して登録します

登録時に入力先の選択文字列は置換しません

保存先

```text
~/Library/Application Support/myim/user/dictionary.txt
```

ユーザー辞書候補は通常の入力で最優先し、同じ階層では直近に選択した順で表示します

候補選択履歴の保存先

```text
~/Library/Application Support/myim/user/candidate-selection-history.json
```

平仮名一文字になる入力だけは、平仮名と片仮名をユーザー辞書候補より優先します

## 次の入力候補

確定した語句の前後関係をローカルで学習し、次に入力される可能性が高い語句を確定直後に表示します

1. 語句を通常どおり確定
2. 学習済みの次入力候補がある場合は候補パネルへ最大7件表示
3. `Tab`で次入力候補パネルへ移り、先頭候補を選択
4. `Tab`、Space、矢印キーで候補を移動
5. `Return`で確定

候補を使わず入力を始める場合は、そのまま文字を入力します

文字、記号、ショートカットの入力や入力位置の変更でも次入力候補を自動で閉じます

候補へ移る前にSpaceを押した場合は、次入力候補パネルを維持したまま通常の半角Spaceを入力します

候補へ移る前の矢印キーは候補選択に使わず、入力先アプリのカーソル操作として扱います

候補へ移った後はSpaceで次候補へ移動します

候補を選択した状態で文字や記号を入力すると、選択中の候補を確定してから新しい入力を開始します

次入力候補パネルは無操作のまま5秒経過すると自動で閉じます

候補を移動すると5秒の待機時間を数え直します

`Shift＋Tab`で前候補へ移動します

`Escape`で次入力候補、Cosenseパネル、OS辞書パネルを閉じます

生の時系列ログは保存せず、最大256文脈、1文脈につき最大8候補の集計だけを保存します

使用頻度を優先し、同頻度では直近の使用を優先します

上限を超えた古い集計は自動で削除します

入力ソースメニューの「次入力履歴を削除」で集計データを削除できます

保存先

```text
~/Library/Application Support/myim/user/next-input-model.json
```

## Tab辞書登録モード

1. 候補を選択していないローマ字入力中に`Tab`を押す
2. 登録する候補文字列を入力するか`Command＋V`で貼り付ける
3. 入力中は通常どおり変換候補が表示されるため、Spaceまたは矢印キーで選択する
4. `Return`で現在の変換部分を登録文字列へ追加する
5. 空白を含める場合は入力部分が空の状態でSpaceを押す
6. 必要なら続きの文字列を入力し、同じ操作で登録文字列へ追加する
7. 入力部分が空の状態で`Return`を押し、ユーザー辞書への保存と本文への確定を行う

候補選択中に記号を入力した場合は、選択候補を登録文字列へ追加してから記号の入力を開始します

候補パネルには読み、入力中の候補文字列、登録と中止のキーを分けて表示します

`Escape`で登録を破棄し、元のローマ字入力と通常候補へ戻ります

## ユーザー辞書候補の削除

1. 削除するユーザー辞書候補を選択する
2. `Command＋X`を押す
3. 候補がローカルユーザー辞書から削除され、候補一覧が更新される

削除した候補文字列はクリップボードへコピーされます

誤って削除した場合は、同じ読みの入力中に`Command＋V`で再登録できます

基本辞書、Cosense拡張辞書、英語補完などユーザー辞書以外の候補は削除されません

## macOS辞書パネル

macOS標準辞書の利用範囲と変換候補への利用方針は`docs/MACOS_DICTIONARY.md`を参照してください

語義は次の辞書から個別に取得し、1つのスクロール領域へまとめて表示します

- スーパー大辞林
- ウィズダム英和辞典・ウィズダム和英辞典
- New Oxford American Dictionary

ウィズダム英和辞典と和英辞典はmacOS上で1つの辞書として提供されます

## コア機能と実験機能

次のコア機能は常時有効です

- ローマ字入力
- ひらがな、片仮名、記号を含む候補生成と候補選択

次の実験機能は入力ソースメニューの「実験機能」欄にあるトップレベルのチェック項目で個別に切り替えます

- 「ローカル基本辞書で変換候補を取得」でMozc OSS、TKGJE、myim補完辞書、動詞活用候補をオン・オフ
- 「ローカルユーザー辞書を使用」で登録済みユーザー候補をオン・オフ
- 「Cosense拡張辞書を使用」で同期済み拡張辞書候補をオン・オフ
- 「英語補完を使用」でmacOSの英語補完候補をオン・オフ
- 「Wikipedia候補を取得」でWikipediaの記事名候補をオン・オフ
- 「日本語入力から英語の変換候補を取得」でApple Translation frameworkによる英訳候補をオン・オフ
- 「Azure英訳候補を取得」でAzure Translator Dictionary Lookupの複数英訳をオン・オフ
- 「Command＋ReturnでWeb検索」で候補確定とブラウザ検索をオン・オフ
- 「次入力候補を使用」で学習と表示をオン・オフ
- 「Cosenseパネルを使用」でページ確認と表示をオン・オフ
- 「macOS辞書パネルを使用」で語義抽出と表示をオン・オフ

設定変更は再起動せず、現在の入力から反映されます

すべての実験機能を無効にしても、ローマ字入力とひらがな・片仮名・記号候補は継続します

Cosenseパネルを無効にすると、候補選択時のページ存在確認とWebView更新も停止します

設定は保存され、myimの再起動後も維持されます

外部通信を伴う候補とWeb検索は初期状態で無効です

## 公式外部候補

1. 入力ソースメニューで使用する候補元を有効にする
2. 2文字以上入力するとローカル候補を先に表示する
3. 入力停止から250ミリ秒後に外部候補を追加する
4. 通常の`Return`で候補文字列を確定する

- Wikipedia候補は日本語版WikipediaのOpenSearch APIから記事名を取得
- Apple翻訳候補はmacOS 15以降のTranslation frameworkを使用
- Apple翻訳で言語モデルが未導入の場合はmacOSがダウンロード許可を求める
- Azure英訳候補はAzure TranslatorのDictionary Lookupを使用
- Azure英訳候補を使う場合は「外部候補とWeb検索を設定…」でAPIキーと必要に応じてリージョンを設定
- Azure APIキーは`~/Library/Application Support/myim/credentials/azure-translator-key.txt`へ権限`0600`で保存

問い合わせには入力中のローマ字をひらがなへ変換した文字列を送信します

通信失敗や応答形式変更時は該当する外部候補だけを省略し、ローカル変換を継続します

非公開のGoogle検索候補エンドポイントは使用しません

## Web検索

1. 入力ソースメニューから「外部候補とWeb検索を設定…」を開く
2. 検索語を挿入する位置へ`%s`を含めたURLを設定する
3. 「Command＋ReturnでWeb検索」を有効にする
4. 任意の候補を選択して`Command＋Return`を押す
5. 候補を確定し、設定したURLを既定ブラウザで開く

初期値は`https://www.google.com/search?q=%s`です

設定例

```text
https://duckduckgo.com/?q=%s
https://www.google.com/search?q=site%3Ascrapbox.io%2Fsendarionn-public+%s
https://ja.wikipedia.org/w/index.php?search=%s
```

`%s`を含まないURL、HTTPまたはHTTPS以外のURLは保存しません

入力ソースメニューは「操作キー＋実行結果」など、操作後の動作が分かる名前を使用します

## Cosense辞書

Cosenseは個人用の語彙や候補順を追加する拡張辞書として使用します

入力ソースメニューから「Cosenseプロジェクトを設定…」を選び、プロジェクトURLを入力します

```text
https://scrapbox.io/project-name
```

指定したプロジェクトの`dictionary`ページを読み込みます

設定直後に自動同期し、プロジェクトURLは次回起動時も保持します

プロジェクトごとの拡張辞書はローカルへ個別にキャッシュします

Cosenseプロジェクトを設定すると、ログイン専用の補助アプリが開きます

ログイン後に「ログイン完了」を押すと、CosenseのCookieだけをmyimへ保存して補助アプリを終了します

ログインとGoogle認証はmyimとは別プロセスで動作するため、入力処理へ負荷を与えません

保存したCookieはページの存在確認とCosenseパネルの両方で使用します

Web Cookieがある場合は、ページ表示の存在確認でPATよりCookieを優先します

Web Cookieを使う存在確認ではURLSessionの自動Cookie処理を無効にし、保存Cookieだけを送信します

再ログインする場合は入力ソースメニューの「Cosenseへログイン…」を開きます

プライベートプロジェクトを使用する場合は、入力ソースメニューの「Cosense認証を設定…」を開きます

- Personal Access Tokenは`https://scrapbox.io`上の参加プロジェクトで共通使用
- Service Accountは現在選択しているプロジェクトだけで使用
- Service Accountが設定されている場合はPersonal Access Tokenより優先
- 認証情報はユーザーだけが読み書きできる権限`0600`のファイルへ保存

設定または削除後に`dictionary`ページを自動で再同期します

認証情報は`Command＋V`または「クリップボードから貼り付け」で入力します

保存先

```text
~/Library/Application Support/myim/credentials/cosense.json
```

HTTP 401は「認証が必要」、HTTP 403は「権限なし」として入力ソースメニューへ表示します

`dictionary`ページでは読みをインデントなしで記述し、その候補を1文字以上インデントします

読みには入力に使用するローマ字を記述します

```text
miru
 見る
 診る
 観る

ikiru
 生きる
 活きる
```

同じ読みが複数回現れた場合は候補を記述順に統合します

重複した候補は最初の候補だけを残します

基本辞書と重複する候補は拡張辞書側を優先します

### 実行中の辞書更新

次のどちらかでCosenseの変更を読み込みます

- 入力ソースメニューから「Cosense辞書を更新」を選択
- `Command＋Option＋Control＋R`を押す

更新した辞書は次の場所へ保存されます

```text
~/Library/Application Support/myim/extensions/<project-name>/dictionary.txt
```

更新に成功すると実行中の変換辞書へ即時反映されます

IMの再起動は不要です

更新に失敗した場合は現在の辞書を維持します

## 実装予定

### 全角記号の拡充

- ASCII記号から全角記号と日本語組版向け記号を候補生成
- 半角、全角、日本語記号を同じ入力から選択可能にする
- 直近の選択履歴を使い、よく使う記号を優先

### 日付と時刻の入力

- `Control＋T`で現在時刻を入力
- 確定直後に`Control＋T`を繰り返すと別の書式へ置換
- `HH:mm`、`HH:mm:ss`、`yyyy-MM-dd HH:mm`などを標準書式として用意
- `YYYYMMDD`などの書式を入力してから`Control＋T`を押すと、指定書式の日付または時刻へ置換
- 許可した書式トークンだけを解釈し、通常の文字列は変更しない

### 外部情報パネルの汎用化

- Cosense専用のページ表示処理を情報ソース共通のインターフェースへ分離
- Cosense、Wikipedia、その他の情報ソースを選択可能にする
- 情報ソースごとに有効化、表示位置、認証、ページ存在確認を管理

## ビルドとインストール

IMバンドルをビルドします

```shell
./Scripts/build-macos-ime.sh
```

ユーザー用Input Methodsへインストールし、入力ソースを再登録します

メニューバーとカーソル位置の入力モードインジケータには小文字`m`を表示します

```shell
./Scripts/install-macos-im.sh
```

初回のみ「システム設定」→「キーボード」→「テキスト入力」→「編集」から`myim`を追加します

更新時は同じ2つのコマンドを再実行します

ログアウトや再起動は不要です

入力ソース切替に使った修飾キー付きSpaceは本文へ入力しません

入力中に`Command＋V`を押すと、入力中のローマ字を読み、クリップボードの文字列を候補として確認なしでユーザー辞書へ登録し、その文字列で確定します

インストール先は次の場所です

```text
~/Library/Input Methods/myim.app
```
