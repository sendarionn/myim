# 任意IDS構成要素データ

候補フィルターの構成要素検索へ、利用者が用意したIDSデータを追加できます

## 配置方法

設定の「候補フィルター」にある「CJKVI IDSデータをダウンロード」から取得できます
取得前に配布元とライセンスを表示し、同意した場合だけダウンロードします

手動で追加する場合は下記の手順です

1. メニューバーのmyimから「候補フィルターデータフォルダを開く…」を選択
2. `.txt`、`.tsv`、`.ids`のいずれかのファイルを配置
3. `⌥F`で候補フィルターを開始

配置先は下記です

```text
~/Library/Application Support/myim/CandidateFilter/IDS/
```

候補フィルターを開始すると更新日時とサイズを確認し、ファイルが変わっている場合だけ再読込するため、myimの再起動は不要です

## 対応形式

CJKVI-IDSやCHISE-IDSで使われる、コード位置、対象文字、IDS記述の順に並ぶ形式を読み込みます

```text
U+4F11	休	⿰亻木
U+76F8	相	⿰木目
U+60F3	想	⿱相心
```

タブまたは空白区切りに対応します
IDS演算子、文字参照、地域タグは検索対象から除外します
`想`から`相`、さらに`木`と`目`まで辿るように、入れ子になった構成要素を再帰的に展開します

## ライセンス

myimはIDSデータを同梱せず、利用者の操作なしにダウンロードしません
ボタンを押して同意した場合だけ、CJKVIの`ids.txt`をApplication Supportへダウンロードします
配置したファイルはApplication Support内の元の場所から読み込みます
データの取得、配置、利用、再配布では各配布元のライセンスに従ってください
